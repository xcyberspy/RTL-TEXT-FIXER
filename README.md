<h2>🧐 Features :</h2>

Here're some of the project's best features:

*   🔀 Mixed-text fix: keeps English words numbers dates URLs and emails in the correct place inside Arabic sentences using the browser's native Unicode bidi support. It never translates rewrites or spell-corrects your text.
*   ↔️ Per-line direction: any line with Arabic displays right-to-left. English-only lines stay left-to-right.
*   ⚡ Live output: the result updates as you type or paste. The word counter shows the 20000-word limit and over-limit text is never cut.
*   📋 Smart copy: Copy puts the corrected text on the clipboard with invisible direction marks plus an HTML version so the fix survives pasting into other apps. It falls back to plain text if the browser blocks rich copy.
*   🔒 Privacy: all processing happens in your browser. Nothing is uploaded logged or tracked. Only the fonts load from Google Fonts.
*   📱 Responsive layout: Input and Output sit side by side on wide screens and stack on phones.
*   🌙 Dark mode: follows your device setting automatically.
*   🧹 Clear button: empties the input in one tap.
*   🔄 Reversed-text recovery: detects Arabic stored backwards and restores it automatically with a "Reversed text restored" notice. Detection is heuristic based on common Arabic words.
